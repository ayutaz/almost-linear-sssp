# Tasks

Single source of truth for work items. Edited by the lead agent only (parallel agents send
updates to the lead). Columns:

- **ID**: `P<phase>-<NAME>`. The prefix is the *phase*, not the priority.
- **Priority**: P0 = blocks other work / required for the reproduction claim, P1 = needed for
  the full study, P2 = nice to have.
- **Status**: TODO / IN_PROGRESS / BLOCKED / DONE.
- **Test Evidence**: `docs/tdd/tasks/<ID>.json` (TDD) or the review/report file for non-code work.
- **Commit SHA**: commit that closed the task (`tdd.py done --commit`).

Phase 3–5 rows were refined from `docs/PAPER_MAPPING.md` (module paths, deviations D-n) and
`docs/research/open-questions.md` (Q-n). Dependencies follow the paper's lemma dependencies.
Section numbers refer to arXiv 2611.34911v1.

Sub-task rows ("part of X" in Dependencies) carry the IDs of the evidence files in
`docs/tdd/tasks/`. Where a planned ID mapped one-to-one onto an evidence file with a different
name, the row was renamed to the evidence ID and the planned ID is kept in the criteria as
"(planned as …)"; dependency references were renamed with it. Commit SHA lists the
implementation commits on `main` (not the merge commits).

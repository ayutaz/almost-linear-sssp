## 0. 要点（面向实现者）

1. **随机性只出现在 Sec 6（NameRoutes 与 Estimate）**。它是 Las Vegas 型的，没有 Monte Carlo 的部分。证书（`d_S(x,y) ≤ Z ≤ Pλ`）的正确性与随机位无关（Lemma 6.7(1) 的无条件上界）。随机性只影响直到某次尝试被接受为止的尝试次数（即时间）。
2. 外层构造（Alg 8 第 8 行以后）仅在 `N > L_N^64` 时运行。满足该条件的最小 N 是 `589^64 + 1 ≈ 1.94×10^177`，因此所有真实输入都走基本情形（基于扫描的 Dijkstra）（`thresholds.md`）。
3. 该构造**不递归**。深度是固定的：Alg 8（外层）→ Alg 7 与 Sec 8.2 内部的 Alg 4（局部，逐 atom）→ Alg 4 内部的"精确 Kruskal 合并树"（atom Y，|Y| < L_k^4）。Alg 8 从不调用自身。
4. 影响正确性的常数（改动它们可能导致距离出错）：Estimate 的 `T ≥ 4t`、尺度上端 `≥ tT²a`、窗口 `[a/T², T²a]`、外层壳比 `K = 16`、Sec 7.3 的 `32q ≤ r < 64q`、重叠判定 `[r/4, 4R]` 与 `16R`、Sec 8.2 的 `F > 2P(2h+1)(8K²h)²`，以及局部的 `K ≥ 8h` 与 macro 判定 `w ≤ N³σ`。
   只影响时间的常数：外层与局部的阈值、`P` 的大小、采样规模 `16t` 与 `32t`、`H`、Sec 3 的块长度。
5. 在浮点实现中，低估 `d_e = Pλ_e`，或在按 `H` 放大后的比较中产生舍入，**可能使放射边删除判定（Sec 8.1）出错，从而删掉一条最短路径**。推荐使用整数权重并做精确比较（饱和移位比较或多精度）（`thresholds.md` §6）。

## 1. Sec 6 基于随机样本的短枢轴路径（p.29–35）

### 1.1 Definition 6.1（枢轴路径证书，p.29，l.1368）

- **输入（枢轴路由实例）**：一个无自环的无向多重图 `G_P`，其顶点是 t 个枢轴。它有 M 条边 `e = xy`。每条边有正长度 `a_e`，即连接 x 与 y 的**物理游走**的长度。
- **路径证书**：对公共因子 `P ≥ 1`，一个输入权重 `λ_e ≤ a_e`，使得存在长度 `≤ Pλ_e` 的物理 x–y 游走。
- **字典（Dictionary）**：作为证书使用的互不相同的权重的有序列表。每条边持有一个字典下标。
- 在应用中（Sec 7.1），`t = O(1 + N/L_N^64)`（N 是物理顶点数）。自环可以事先丢弃。

### 1.2 Sec 6.1 的预处理（l.1382–1392）

- 把每一类平行边替换为一条权重最小的代表边。从每条原边保留一个指向其代表边的指针。代表边的证书对该类中的每条边都有效（`a_e ≥ a_rep`）。
- 代表边图是简单图，边数 `≤ t²`。这只用于限制采样轮数；首次与最后一次扫描计入原来的 M。
- **中位数剪枝**：在一组中找出满足 `P·a* ≥ Z` 的最小 a*。用 BFPRT（Lemma 3.1）选出中位数 m，经 `log2 P` 次加倍得到 `P·m`，并与 Z 比较。若比较成立，则把 m 保留为候选，并转向**严格小于** m 的键。否则转向**严格大于** m 的键（两种情况下，等于 m 的键都被舍弃）。剩下的候选中最小者即为答案。

### 1.3 Algorithm 5 `NameRoutes(G_P)`（p.30，l.1395–1418）

**输入** 一个 Definition 6.1 的实例。**输出** 一个有序字典、每条输入边的字典下标，以及因子 P。

```cpp
// Alg 5 l.2-3
u = ceil_log2(t + 2);  g = 4*u + 3;
P = pow2_ge(8 * 256 * g * u * u);          // 不小于 2048·g·u² 的最小 2 的幂（用整数计算）
if (t < 2) return {empty_dict, {}, P};     // l.1422: 不存在边
// l.4: 选取代表边（按端点对 (min,max) 做稳定计数排序 → 每个端点对内取最小 a，相同时取 id 最小者）
rep[o] = 原边 o 的代表边; U = 代表边列表;
vector<Rec> dict; vector<int> ptr(|U|);    // ptr: 代表边 → 字典记录
while (U.size() > 32 * t) {                // l.5
  S = random_subset(U, 16 * t);            // l.6: 期望 O(|U|) 时间的部分 Fisher-Yates
  auto [table, idx, disc] = Estimate(S, endpoint_pairs(U));   // l.7
  groups = bucket_by(idx, U where !disc);  // l.8: 按下标做计数排序
  qualified = {};  astar_of_group = {};
  for (grp : groups) {                     // l.9
    Z = table[grp.index];
    optional<W> a = median_prune(grp.weights, Z, P);   // l.10
    if (a) for (e : grp) if (a_e >= *a) qualify(e, *a);  // l.11-12
  }
  if (2 * qualified.size() >= U.size()) {  // l.13: 至少一半合格则接受
    for (grp with a*) { r = dict.push(a*); for (e qualified in grp) ptr[e] = r; }   // l.14
    U.remove(qualified);
  } // 否则丢弃全部提案，用新的随机位重试（l.1421）
}
for (e : U) ptr[e] = dict.push(a_e);       // l.15: 剩下的用各自的权重作为证书
sort(dict by weight); coalesce ties → newidx;   // l.16
for (o : original edges) name[o] = newidx[ptr[rep[o]]];
return {dict, name, P};                    // l.17
```

- **不变式**：每次被接受的轮次之后，从 U 中移除的每条边都持有有效证书（l.1421）。
- **随机化**：S 是 U 的均匀 16t 元素子集。在 Estimate 内部，每个尺度还会独立抽取一个均匀排列和一个均匀整数 j。失败的轮次整体丢弃，并用新的随机位重新抽取。**Las Vegas 型**。一轮的接受概率 ≥ 1/2（Lemma 6.8(2)）。
- **计算模型**：权重只使用比较、加法与加倍（`P·m` 用加倍，BFPRT 用比较）。下标与分组使用整数计数排序。随机数使用 Sec 2 的拒绝法（抽取 `⌈log2 h⌉` 位，若值不小于 h 则重抽）。
- **退化情形**：若 `t < 2`，为空。若 `|U| ≤ 32t`，不做采样，所有边都视为终端边。即使所有边权重相同，中位数剪枝也能正确工作（相等的键在两侧都被舍弃）。
- [Supplement] `2·|qualified| ≥ |U|` 中的"至少一半"，是把论文的"at least half"直接用整数比较。

### 1.4 Lemma 6.2（关键边，p.30，l.1424）

- 命题：令 `g = 4⌈log2(t+2)⌉ + 3`。若删除某条边后，其端点无法再通过一条"至多 g 条边、每条边权重 ≤ 被删除边的权重"的路径相连，则称该边为**关键边**。关键边**至多 2t 条**。
- 证明概要：关键子图是简单图，且没有长度 ≤ g+1 的环。反复删除度 ≤ 2 的顶点并记账。剩下的子图最小度 ≥ 3，因此深度为 `j = ⌊g/2⌋` 的 BFS 产生 `3·2^{j−1} > t` 个顶点，矛盾。
- 检查：`3·2^{2u} > t` 恒成立（对 t < 2×10^5 已穷举验证）。
- **测试**：在小的随机多重图上，用暴力方法数出关键边并检查 `≤ 2t`。

### 1.5 Lemma 6.3（均匀样本中的距离，p.30，l.1439）

- 命题：设剩余集 U 有 `h > 32t` 条边，S 是其中均匀的 16t 条边子集。满足 `d_S(x,y) > g·a_e` 的边 e 的期望数量 ≤ h/8（包含不连通的点对）。
- 证明：后向分析。若 e 从 U\S 中均匀选取，则 S∪{e} 中每条边成为 e 的可能性相同。恰当 e 在 S∪{e} 中是关键边时才没有见证。期望 ≤ `(h−16t)·2t/(16t+1) < h/8`（已用数值检查）。
- **测试**：在大量随机种子上，经验地检查满足 `d_S > g·a_e` 的比例的均值 ≤ 1/8。

### 1.6 Sec 6.2 Algorithm 6 `Estimate(S, Q)`（p.31–33，l.1455–1508）

**输入** 一个正权重的样本图 S（O(t) 条边）以及 h 个端点互不相同的请求。**输出** 一张上界表，以及每个请求对应的表下标或不连通标志。

```cpp
T = pow2_ge(4 * t);                         // l.1473
sort S by (w, id);                          // 相邻 run 的归并排序，O(t log t)
// band: 最小的未分配权重 a 开启一个 band，它包含权重 a ≤ w < T·a（T·a 用 log2 T 次加倍）
// Kruskal 扫描: 每次 union 创建一个二叉父结点 (weight, band id) → 合并森林 (l.2)
for (q : Q) if (find(x) != find(y)) disc[q] = true;
            else band_of[q] = band(LCA_mergeforest(x, y));     // l.3 (Lemma 3.9)
for (a : 有需求的 band 的锚点，按递增顺序) {   // l.4
  // 商图 Q_a (l.1481–1488): 收缩权重 < a/T² 的边（以 T²w < a 来判定）。
  //   当所选森林边低于收缩截止值时，把它们插入。
  //   标签通过对较小的列表重新标号来维护。两个游标维护窗口 [a/T², T²a]。
  //   保留的边: 位于窗口内且收缩后端点不同的边。顶点: 仅限与保留边相关联者。
  build Q_a; 按分量标签映射需求端点;            // l.5
  ell = 满足 2^ℓ ≥ t·T² 的最小 ℓ;   // 尺度 Δ_i = 2^i·a, i = 0..ell
  H = pow2_ge(pow(16*t, 5));
  for (i = ell; i >= 0; --i) {                                    // l.6-7
    perm = uniform_permutation(V(Q_a));  j = uniform_int(0, H-1);
    // 半径 R = Δ(1 + j/H)。按 H·dist ≤ (H+j)·Δ 比较 (l.1493)
    best[] = +∞ (用时间戳做惰性初始化); label[] = none;
    for (c : perm) radius_limited_dijkstra(c, R):                 // 二叉堆
        // 顶点 z 在距离 d 处被确定时，仅当 d < best[z]（严格）才
        // 设 best[z] = d 并扫描其边。否则舍弃这次访问。
        // 第一次改进时，label[z] = c（永久）。
  }
  // l.8-9: 在每个商图分量中，从粗到细的尺度构建划分树。
  //   尺度 Δ 上的一个 part 是一个对 (父 part, label)。用稳定计数排序分组。
  //   对每个新 part，把值 4Δ + a (= a·2^{i+2} + a) 写入全局表。
  //   在最细的 part 之下为每个顶点挂一个叶子。LCA 预处理。
  for (q in band a) idx[q] = table_index(LCA(leaf(x'), leaf(y')));   // l.10
}
return {table, idx, disc};                                         // l.11
```

- **不变式**：位于尺度 Δ 上同一 part 内的顶点，在该尺度上有相同的中心（l.1507）。在顶层尺度 `Δ ≥ tT²a` 上，第一个中心覆盖整个商图分量（Lemma 6.7(1)）。
- **计算模型**：权重使用比较、加法与加倍（T²、乘以 H、`(H+j)Δ`）。H 与 j 是整数，约 `log2 H = 5·log2(16t)` 位的多字整数（`thresholds.md` §5）。Dijkstra 使用二叉堆（Lemma 3.2，每次操作一个 log）。
- [Supplement] `ell` 的定义"使最后一个尺度 `≥ tT²a` 的最小 ℓ_a"，在整数下等价于 `2^ℓ ≥ t·T²`（因为 a > 0）。

#### Lemma 6.4（提升商图路径，p.32，l.1509）

- 命题：若 x、y 是互不相同且连通的样本顶点，其合并权重为 β，所在 band 的锚点为 a，则它们在 Q_a 中的像互不相同、存在且连通。对商图距离 d，有 `a ≤ β ≤ d ≤ d_S(x,y) ≤ d + a`。
- 这是确定性命题。用到的事实是 `(t−1)β < T²a`（`T > t−1`），以及提升所增加的长度 `t²a/T² ≤ a`（`T ≥ t`）。
- **测试**：在随机 S 上，对每个连通请求检查这四个不等式。

#### Lemma 6.5（单一尺度上的分离，p.33，l.1530）

距离为 d 的两点在尺度 Δ 上得到不同中心的概率 `≤ H_t(d/Δ + 1/H)`，其中 `H_t = Σ_{i≤t} 1/i`。证明与 FRT 中的排序论证相同。

#### Lemma 6.6（为一个尺度分配标签的工作量，p.33，l.1542）

剪枝搜索为每个顶点返回其"首个覆盖它的中心"（正确性由归纳得出，确定性）。期望时间为 `O((v+e)·log²(t+2))`。每个顶点的期望扫描次数 ≤ H_t，每次堆操作一个 log。在固定半径的条件下同样成立。

#### Lemma 6.7（样本估计器，p.33–34，l.1560）

- 命题：t ≥ 2 个枢轴，O(t) 条边。表有 `O(t log(t+2))` 项，期望时间为 `O(h + t log³(t+2))`。不连通的点对能被识别。对连通的请求，
  `d_S(x,y) ≤ Z`（**确定性**），`E[Z | S] ≤ 256u²·d_S(x,y)`，`u = ⌈log2(t+2)⌉`。
- 证明要点：(1) 在一个 part 内，到公共中心的距离 < 2Δ，所以 `d_S ≤ 4Δ + a`（由 Lemma 6.4）。(2) `Z ≤ 5a + 8ΣΔ·I_Δ`，`E[Z|S] ≤ 5a + 8H_t((ℓ_a+1)d + ΣΔ/H)`。由于 `H_t ≤ 2u`、`T < 8t`、`ℓ_a+1 ≤ 7u`（对 t < 10^5 已用数值检查），以及 `ΣΔ < 4tT²a`，`H ≥ (16t)^5` 给出 `ΣΔ/H ≤ a ≤ d`。(3) 每条边至多进入 5 个窗口，因此商图的总规模为 O(t)。
- [Note] `ΣΔ/H ≤ a` 只需要 `H ≥ 4tT²`，所以 `(16t)^5` 是带有余量的取值（Mode B 中降低 H 的依据；H 只影响时间）。
- **测试**：(a) 每个请求 Z ≥ d_S（确定性，所以每次都成立）。(b) 经验上 `mean(Z/d_S) ≤ 256u²`。(c) disc 标志与 S 的连通分量一致。(d) 表项数 ≤ c·t·log t。

### 1.7 Lemma 6.8（枢轴路径证书，p.34–35，l.1605）

- 命题：在 `t = O(1 + N/L_N^64)` 的无自环实例上，Alg 5 为每条边给出 Definition 6.1 意义下的证书。字典有 `O(t log²(N+2))` 项。P 是量级为 `log³(t+2)` 的 2 的幂。它**几乎必然终止**，期望时间为 `O(M + N)`（包含有序字典）。
- 证明要点：
  1. 对被接受的边，`a* ≤ a_e` 且 `d_S ≤ Z ≤ Pa*`。把 S 中一条最短路径所代表的物理游走串接起来即得证明。终端边由其自身权重来证明。
  2. 在一次尝试中，对 `d_S ≤ g·a_e` 的请求，由 Markov 不等式与 Lemma 6.7 得 `Pr[Z > P·a_e | S] ≤ 1/8`（因为 `P ≥ 8·256·g·u²`）。失败的期望数量 ≤ h/8 + h/8 = h/4。被拒绝（失败数 > h/2）的概率 ≤ 1/2。
  3. 一次尝试的代价为 `O(h + t log³ t)`。到达第 i 次尝试的概率 ≤ 2^{1−i}。
  4. 每个被接受的轮次使剩余集减半。被接受的轮次有 `O(1 + log t)` 轮，终端边 ≤ 32t 条。字典排序需要 `O(t log³ t)`。`O(t log⁴ t) = O(N)` 用到枢轴数假设 `t = O(N/L^64)`。
- **随机化类别**：Las Vegas 型。失败（被拒绝）时，在同一剩余集上用新的随机位重试。重试次数没有上界（几乎必然终止）。
- **测试**：对每条边 e，`λ_e ≤ a_e` 且 `dist_{G_P}(x,y) ≤ P·λ_e`（以 G_P 上的 Dijkstra 为参照）。字典有序且无重复。尝试次数与接受率的统计（接受率 ≥ 1/2）。所有不变式在各随机种子下都成立。

## 2. Sec 7 到所属枢轴的辅助距离（p.35–41）

### 2.1 Sec 7.1 边的分类与辅助度量（l.1642–1660）

- 外层使用 Sec 5 的 owner 分解，**分离规模 `b = L_N^64`**。`r_v = b_T(v, p(v))`（树路径上的最大边），`R_v = D_T(v, p(v))`（树上距离），`h = b + 1`。本节的 macro 规则取代局部的规则（`w ≤ N³σ`）。
- 对每条跨越 owner 的边 `xy`，投影长度 `A_e = R_x + w + R_y ≤ (2h+1)w`（Lemma 5.2）作为枢轴路由实例的边长传给 Lemma 6.8。顶点是枢轴，`t = |A|`。
- 由名字 λ_e 得到 `d_e = P·λ_e`（每个名字做一次，经 log2 P 次加倍）。
- **分类**：跨越 owner 的边，若 `2d_e ≤ w` 则为**放射（radial）**边，否则为 **macro** 边。同一 owner 内的边是放射边，`d_e = 0`。

#### Lemma 7.1（p.35，l.1653）

每条被切割的走廊（corridor）边都是 macro。权重为 w 的 macro 有名字 λ，满足 `λ/(2h+1) ≤ w < 2Pλ`。对被切割的边 f，由 MST 的割性质可得 `d_f ≥ w(f) > 0`。
**测试**：对每条 macro 边检查这两个不等式。所有走廊边都是 macro。

### 2.2 Sec 7.2 owner 坐标（l.1662–1690）

- 把所有枢轴识别为一个点 `a`。保留放射边，其辅助长度为 `w'_e = w_e + d_e`，并保留 owner MST 的所有辐条（spoke）。这些辐条构成新图的 MST `T'`。丢弃 a 处长度为正的自环。`J_v = d_{w'}(v, a)`。在枢轴处，`J = 0`。

#### Lemma 7.2（owner 坐标的物理解释，p.35，l.1668）

- 命题：`J_v` 是从 v 到其所属枢轴的物理路径长度的上界。`r_v ≤ J_v ≤ R_v ≤ h·r_v`。在放射边上，`|J_x − J_y| ≤ w'_e ≤ 3w_e/2`。`T'` 是识别之后的 MST。
- **测试**：用参照 Dijkstra 在 G' 上计算 J，并在每个顶点与每条放射边上检查这些不等式。检查 `T'` 是 MST（其权重之和是否与 Kruskal 一致）。

### 2.3 Sec 7.3 宽度类、日历与 atom（l.1692–1779）

数据结构与步骤（l.1693–1710）：

```cpp
// r_v, R_v 在 T' 上自顶向下: a 的孩子 v 有 r=R=w(av)。否则 r_v = max(r_u, w), R_v = R_u + w
// 树片 P: 保留 T'−a 中区间 [r/4, 4R] 相互重叠的父子边 (u,v)

// 跨越图片的边 uv (定向为 r_v > 16R_u): 标记弧 U+_u → 16q_v

// atom: 权重 w' < 2·max(q_u,q_v) 的非枢轴边的连通分量 Y (并查集)
//   Y 的物理生成树 (定义边) 及其权重和 L_Y (≤ 2q|Y|)
// 初始化: 在每个 v 处放置可行的上界 R_v，再加上与 s 相关联的边给出的报价
```

#### Lemma 7.3（重叠范围的倍频程跨度，p.36，l.1711）

对所有图片，从最小 r 到最大 R 的二进网格点数（两端各含常数个）为 O(N)。每个顶点的宽度与上标记下标可在 `O(1 + log log(b+4))` 时间内找到。
证明要点：在树片的根处，`R_x ≤ 17r_x/16`。在保留的边上，`R_v ≤ 17R_u`。按图重叠合并时，每条连接边只增加常数个倍频程。

#### Lemma 7.4（统计宽度单元，p.36，l.1736）

所有 (C, q) 日历的单元总数，以及合并标记点的时间，均为 O(N)。权重为 w 的树边贡献 `Σ_{q>w/64} w/q = O(1)`。

#### Lemma 7.5（辅助宽度下的 atom 大小，p.37，l.1751）

一个 atom 属于一个图片和一个宽度，且有 **< b 个顶点**。其定义边给出一棵生成树，每条边 < 2q。理由：定义边的两个端点具有相同的 r，且 T' 中的路径不经过枢轴，因此它位于去掉枢轴之后的某一个分量内（< b 个顶点）。

#### Lemma 7.6（p.37，l.1762）

网格与日历总共有 O(N) 项。构造需要 `O(m + N log log(b+4))`。atom 的顶点数 < b。**每条标记弧都使数值时间增大**（`U+_u ≤ 2R_u < r_v/8`，`16q_v > r_v/4`）。

**Sec 7.3 的测试（中间状态）**：在每个顶点上 `32q_v ≤ r_v < 64q_v` 且 `R_v < U+_v ≤ 2R_v`。在跨越片的边上 `r_v > 16R_u`。标记 DAG 无环，且每条弧都指向值增大的方向。单元总数 / N 有界。对每个 atom，`|Y| < b`，q 与 C 是统一的，`L_Y ≤ 2q|Y|`，且 `T'[Y]` 连通。

### 2.4 Sec 7.4 局部搜索、截断与外部到达（l.1780–1963）

**族（family）与激活列表**（l.1781–1800）：
- 一个 atom 属于其代表元的 (P, q) 所对应的族。在一个族内，按 T' 的先序（整数排序）对代表元排序。相邻代表元之间的间隔 `g(i,j)` 按树上距离计算（LCA 与到根的距离）。
- 族的视界（horizon）为 `max_{Y∈family}(R_rep(Y) + L_Y)`。对 `v ∈ Y`，`R_v ≤ R_rep(Y) + L_Y`。
- 从单元 0 开始沿该族的 (C, q) 日历前进，直到"起点 ≤ 视界"不再成立，或走到日历末尾。把族记录推入每个单元起始标记点的激活列表。

**族内的 run 管理**（l.1801–1815）：
- 已登记 atom 的链表，以及未登记 atom 的连续 run。在单元 `[a0, b0)` 中，在包含最先到期的最小 z 的 atom i 处拆分 run。对每个新产生的子 run（至多 2 个），把 `u = max{b0, z + L_i + g(i,j)}` 作为报价，提供给与 i 相邻的边界 atom j 的代表元 v 的原生入向副本。若 `u > R_v`，或它没有降低待定键，则丢弃。
- 拆分与取最小值（split–findmin）总共需要 `O(m + Nτ(N))`（Lemma 3.11）。

**atom 的局部表示**（l.1816–1833）：
- 每个 atom Y 使用带辅助长度的整个诱导图 `G'[Y]`（包括重弦）。离开 atom 的出口列在其尾端。
- 抑制出口：若发出时间 `> R_u`，则不从尾端 u 发出。若外部报价 `> R_v`，则丢弃发往头端 v 的外部报价。在跨越图片的边中，只保留从范围较小一侧指向范围较大一侧的方向。
- 族的登记时间 z 与 L_Y 决定持续截止期 `z + L_Y`（含端点）。
- Y 是截止值为 q 的可替换 atom（Definition 5.11）。由 Lemma 5.13 与 5.14，构造封顶为单个根的局部层次结构，并用 Lemma 4.3 将其规范化。内部单位 ≤ q。

**访问活跃 atom**（l.1835–1841）：对单顶点的根，发出一次到期的最小值，松弛被允许的出口，并让该叶子退役。对内部根，在第一个到期键 D0 处打开它，并设上限 `c = min(atom 截止期, D0 + S(root))`（含端点）。在每个单元中，对名义根槽（其与该单元的交集包含 ≤ c 的时间）调用 `Scan(root, I, c)`。恢复被截断的槽时，从第一个存活的子级秩开始，登记、报价与截止期保持不变。

#### Lemma 7.7（被日历截断的槽，p.39–40，l.1871）

- 假设：一个带种子的有序层次结构，单个根，单位 ≤ q。外部报价是可行的，在其时间戳所在单元被访问之前到达，且不会进入当前单元左端点以下。第一个单元的起点不高于每个有限的初始时间戳。被访问的单元覆盖所有受保护的时间戳（包括等于截止期的）。

#### Lemma 7.8（外部报价的时间顺序，p.40–41，l.1919）

atom 间的报价 `z + w'` 仅在被允许的方向上、且仅当 `z ≤ R_u` 且 `z + w' ≤ R_v` 时保留。有效的下降在目标单元的起始标记点之前到达。一条紧的 atom 间步通过所有方向与端点测试。证明按情形讨论（跨越片时用弧 `U+_u → 16q_v`；在同一片内用 `w' ≥ q_u + q_v`）。

名字给定之后，Alg 7 在 `O(m + Nτ(N))` 时间内**确定性地**计算出所有 J_v。`τ(N) = 1 + log log log(N+16)`。
正确性由对标记顺序的归纳，加上 Lemma 5.14、7.7 与 7.8 得出。

**Sec 7.4 的测试**：J 与 G' 上的参照 Dijkstra 一致。对照到达时间日志检查"在目标单元的起始标记点之前到达"（Lemma 7.8）。族视界 `R_v ≤ R_rep + L_Y`。发出的值永不低于下界（真实的 J）（Lemma 4.6 的"无低估"）。退化输入，例如单个 atom、单个族，或所有顶点都在一个单元中。

#### Lemma 8.1（p.42，l.2002）

- 命题：存活的放射边满足 `w ≤ 2(J_x + J_y)`。若在最小坐标处拆分一段全局最短的放射 run，则入向一侧与出向一侧各自的摆幅至多为 16 倍。普通图实现每一条测地线。不含 macro 弧的增广商图无环。

#### Lemma 8.2（到达 macro 边的瓶颈，p.43，l.2027）

`B0 = max(I0, O0)` 与 `θ = max(I*, O*)` 同时有限，且在有限时 `r ≤ θ` 且 `B0 ≤ θ ≤ 4K²h·B0`（K = 16 时为 1024h）。
**测试**：在每个状态上，用暴力瓶颈最小化路径算出 θ 与 B0，并检查这些不等式。

#### Lemma 8.3（p.43–44，l.2053）

对任意 W > 0，块 MST 边、在 θ 处的状态 → owner 连接，以及权重 ≤ W 的走廊边，恰好刻画了由长度 ≤ W 的弧所强连通的状态分量。严格不等式版本（< W）同样成立。
**测试**：对随机 W，Tarjan 的 SCC（弧 ≤ W）与限制在状态上的连接的并查集分量一致。

### 3.3 Sec 8.3 单源算法与主定理证明（p.45–47）

#### Lemma 8.5（恢复前驱树，p.45，l.2145）

由收缩零边分量之后得到的距离，在 `O(m + n)` 内恢复所有原始距离以及一棵最短路径树。沿带方向的紧弧 `d(u) + w(uv) = d(v) < ∞` 前进，并由最先被发现的弧构建树。输出距离通过在沿树下降时累加原始边权来重新计算。

| Alg 4 内部的 atom（Sec 5.4） | 块内权重 < t_U 的边的分量 Y（< L_k^4 个顶点） | 精确的局部 Kruskal 合并树（对 < b 条 MST 边排序） | 总计 O(N log(b+2)) |
| Alg 5 l.5 | `|U| ≤ 32t` | 剩下的用各自的权重作为证书 | 线性 |
| Alg 5 | `t < 2` | 空字典 | O(1) |

**期望复杂度 `O(m + n log log log n)` 的分解**（主定理的证明，l.2206–2216）

| 阶段 | 依据 | 代价 |
|---|---|---|
| l.2 收缩与可达性，l.16 恢复 | 图遍历，Lemma 8.5 | O(m + n) |
| l.8 MST | Lemma 3.5（Fibonacci 堆，三级，B1 = max(2,⌈log L⌉)，B2 = L） | O(m + Nτ(N)) |
| l.8 owner 单元与删除被支配边 | Sec 5.1，LCA | O(m + N + \|A\| log \|A\|) |
| l.9 NameRoutes | Lemma 6.8（**期望**，唯一的随机性） | O(M + N)，由 t = O(N/L^64) 得 t log⁴ t = O(N) |
| l.10 分类与 d_e | 每个名字 log P 次加倍 | O(m + t log² N · log log N) |
| l.11 J | Lemma 7.9（确定性）。局部层次结构 O(m + N log log(b+4))，split–findmin O(m + Nτ(N)) | O(m + Nτ(N)) |
| l.12–13 外层表示 | Sec 8.1（K = 16 所以网格是线性的），Lemma 8.4、5.15 | O(m + Nτ(N)) |
| l.15 求值 | Lemma 4.7 | O(m + Nτ(N)) |

这里，对 `b = L^64`，`log log(b+4)` 为 `6 + log log L + o(1) = O(log log log N) = O(τ(N))`（l.2211–2212）。三重对数来自两个来源：(i) 局部构造中每个顶点的 `log log k`（k ≤ polylog N），以及 (ii) 对全局事件在 `O(log log N)` 个 2 的幂的范围上做二分查找。

## 5. 歧义与注意事项

1. [Ambiguous] Sec 8.1 令 `s_U = min_{v∈U} r_v`（l.1999），而 Sec 5.4 的局部版本令 `s_U` 为"窗口最低壳的下端"（l.1184）。由于 Lemma 8.4(1) 在外层同样使用"半径最小的 v"，把外层读作 `min r` 是一致的。
2. [Ambiguous] Sec 7.3 的网格是"从原点以下至少 7 个倍频程到最大 R 以上 2 个倍频程"（l.1698），而 Lemma 7.3 的证明只说"常数个倍频程"。由于 q = 网格下标 − 5，下方至少需要 5 个倍频程。我们照原样采用 7。
3. [Ambiguous] 局部阈值 `N > 2L^4` 中"2"的作用没有说明。Sec 5.4 的不等式（N ≥ 32、h ≤ N、K < 16h）实际需要的是 `N ≥ 28 ∧ h ≤ N`（⇔ `N > L^4`），这更弱（`thresholds.md` §4）。
4. [Ambiguous] Lemma 6.8 的陈述把字典规模写作 `O(t log²(N+2))`，而证明给出 `O(t log²(t+2))`（因为 t ≤ N，并不矛盾）。
5. [Ambiguous] 在为 Alg 6 的"每个 band 的尺度树"自最粗尺度构建时，一个商图分量在顶层尺度上恰好成为一个 part，这一点由 Lemma 6.7(1) 得出，但正文的步骤中没有写明。[Supplement] 顶层 part = 商图分量。
6. [Ambiguous] 我们把 Alg 7 l.9 的"来自根的直接报价"解释为：把 G' 中与 a 相关联的每条放射边（原本是与枢轴相关联的边）的 `w'`，放在其另一端点的原生入向副本处（J 从 (a, 0) 开始，l.1819）。我们把 Sec 7.3 末尾（l.1710）的"与源点相关联的边给出的报价"读作在 J 的语境下指根 a。
7. [Note] Lemma 6.7 使用 `H ≥ (16t)^5`，但证明只需要 `H ≥ 4tT²`。
8. [Note] 在最小的 N，即 `589^64 + 1` 处，可能出现 |A| = 1。此时 NameRoutes 为空，每条边都是放射边，J 变成从枢轴出发的完整 SSSP，所以整个外层机制都是多余的工作。只有当 N/b 足够大时，外层才有意义。
9. [Note] Alg 8 l.5 的基本情形指定使用"基于扫描"的 Dijkstra（O(N²)）。这一选择只在常数规模下才合理，因此当 Mode A 处理真实的 N 时，使用二叉堆版本（同在 Lemma 3.2 中）是合理的。输出相同。把它记录为偏离（`thresholds.md` §7）。

## 0. 全体の要点（実装者向け）

1. **乱択は Sec 6（NameRoutes と Estimate）だけ**。Las Vegas 型で、Monte Carlo の部分は無い。証明書の正しさ（`d_S(x,y) ≤ Z ≤ Pλ`）は乱数によらず決まる（Lemma 6.7(1) の無条件の上界）。乱数が影響するのは、試行が受理されるまでの回数（＝時間）だけ。
2. 外側の構成（Alg 8 の 8 行目以降）は `N > L_N^64` のときだけ動く。この条件を満たす最小の N は `589^64 + 1 ≈ 1.94×10^177` で、現実の入力ではすべて基本ケース（走査型 Dijkstra）になる（`thresholds.md`）。
3. 構成は**再帰しない**。深さは固定で、Alg 8（外側）→ Alg 7 と Sec 8.2 の中で Alg 4（局所、原子ごと）→ Alg 4 の中の「正確な Kruskal 併合木」（原子 Y、|Y| < L_k^4）。Alg 8 が自分を呼ぶことは無い。
4. 正しさにとって重要な定数（変えると距離が誤りうるもの）: Estimate の `T ≥ 4t`、尺度の上端 `≥ tT²a`、窓 `[a/T², T²a]`、外側の殻比 `K = 16`、Sec 7.3 の `32q ≤ r < 64q`・重なり判定 `[r/4, 4R]`・`16R`、Sec 8.2 の `F > 2P(2h+1)(8K²h)²`、局所の `K ≥ 8h`・マクロ判定 `w ≤ N³σ`。
   時間だけに効くもの: 外側と局所の閾値、`P` の大きさ、標本サイズ `16t`・`32t`、`H`、Sec 3 のブロック長。
5. 浮動小数で実装すると、`d_e = Pλ_e` の過小評価や、`H` 倍に伸ばした比較での丸めによって、**半径辺の削除判定（Sec 8.1）が誤り、最短路を消すおそれがある**。整数の重み＋正確な比較（飽和シフト比較や多倍長）を勧める（`thresholds.md` §6）。

## 1. Sec 6 Short Pivot Routes from Random Samples（p.29〜35）

### 1.1 Definition 6.1（Pivot route certificate、p.29、l.1368）

- **入力（pivot-routing instance）**: t 個のピボットを頂点とする、ループの無い無向多重グラフ `G_P`。辺 `e = xy` は M 本。各辺は正の長さ `a_e` を持ち、これは x と y を結ぶ**物理的な walk** の長さ。
- **経路証明書**: 共通の係数 `P ≥ 1` に対し、入力重みのひとつ `λ_e ≤ a_e` であって、長さ `≤ Pλ_e` の物理的な x–y walk が存在するもの。
- **辞書**: 証明書として使う相異なる重みの、整列済みの一覧。各辺は辞書の添字を 1 つ持つ。
- 応用（Sec 7.1）では `t = O(1 + N/L_N^64)`（N は物理頂点数）。ループは事前に捨ててよい。

### 1.2 Sec 6.1 の前処理（l.1382〜1392）

- 平行辺の組は、重み最小の代表 1 本に置き換える。元の各辺から代表へのポインタを持つ。代表の証明書は組の全辺に有効（`a_e ≥ a_rep`）。
- 代表グラフは単純グラフで、辺は `≤ t²` 本。これは標本抽出の回数を抑えるためだけのもので、最初と最後の走査は元の M に課金する。
- **中央値による絞り込み（median pruning）**: 群の中で `P·a* ≥ Z` を満たす最小の a* を求める。中央値 m を BFPRT（Lemma 3.1）で選び、`P·m` を `log2 P` 回の倍化で作って Z と比べる。成り立てば m を候補として残し、m より**真に小さい**キーへ進む。成り立たなければ m より**真に大きい**キーへ進む（m と等しいキーはどちらの場合も捨てる）。最後に残った最小の候補が答え。

### 1.3 Algorithm 5 `NameRoutes(G_P)`（p.30、l.1395〜1418）

**入力** Definition 6.1 の instance。**出力** 整列済みの辞書、入力辺ごとの辞書添字、係数 P。

```cpp
// Alg 5 l.2-3
u = ceil_log2(t + 2);  g = 4*u + 3;
P = pow2_ge(8 * 256 * g * u * u);          // 2048·g·u²以上の最小の2冪（整数で計算）
if (t < 2) return {empty_dict, {}, P};     // l.1422: 辺が存在しない
// l.4: 代表の選択（端点対 (min,max) で安定な計数ソート → 対ごとに a 最小、同値は id 最小）
rep[o] = 元の辺 o の代表; U = 代表の一覧;
vector<Rec> dict; vector<int> ptr(|U|);    // ptr: 代表 → 辞書レコード
while (U.size() > 32 * t) {                // l.5
  S = random_subset(U, 16 * t);            // l.6: 部分 Fisher-Yates で O(|U|) 期待時間
  auto [table, idx, disc] = Estimate(S, endpoint_pairs(U));   // l.7
  groups = bucket_by(idx, U where !disc);  // l.8: 添字で計数ソート
  qualified = {};  astar_of_group = {};
  for (grp : groups) {                     // l.9
    Z = table[grp.index];
    optional<W> a = median_prune(grp.weights, Z, P);   // l.10
    if (a) for (e : grp) if (a_e >= *a) qualify(e, *a);  // l.11-12
  }
  if (2 * qualified.size() >= U.size()) {  // l.13: 半数以上が合格なら受理
    for (grp with a*) { r = dict.push(a*); for (e qualified in grp) ptr[e] = r; }   // l.14
    U.remove(qualified);
  } // そうでなければ提案をすべて捨て、新しい乱数でやり直す（l.1421）
}
for (e : U) ptr[e] = dict.push(a_e);       // l.15: 残りは自分の重みを証明書にする
sort(dict by weight); coalesce ties → newidx;   // l.16
for (o : original edges) name[o] = newidx[ptr[rep[o]]];
return {dict, name, P};                    // l.17
```

- **不変条件**: 受理された各回の後、U から取り除かれた辺はすべて有効な証明書を持つ（l.1421）。
- **ランダム化**: S は U の一様な 16t 元部分集合。Estimate の内部でも、尺度ごとに独立な一様置換と一様整数 j を引く。不合格の回は全部捨てて、新しい乱数で引き直す。**Las Vegas**。1 回の受理確率は ≥ 1/2（Lemma 6.8(2)）。
- **計算モデル**: 重みは比較・加算・倍化だけを使う（`P·m` は倍化、BFPRT は比較）。添字・群分けは整数の計数ソート。乱数は Sec 2 の棄却法（`⌈log2 h⌉` ビットを引き、h 以上なら引き直す）。
- **退化ケース**: `t < 2` なら空。`|U| ≤ 32t` なら標本抽出をせず、全辺が終端の扱い。全辺が同じ重みでも median pruning は正しく動く（等値を両側で捨てる）。
- 【補完】`2·|qualified| ≥ |U|` の「半数以上」は、論文の "at least half" をそのまま整数で比べたもの。

### 1.4 Lemma 6.2（Critical edges、p.30、l.1424）

- 主張: `g = 4⌈log2(t+2)⌉ + 3` とする。ある辺が **critical** であるとは、その辺を消すと、端点どうしを「辺数 ≤ g、各辺の重み ≤ 消した辺の重み」の路で結べなくなること。critical な辺は **≤ 2t 本**。
- 証明の骨格: critical 部分グラフは単純で、長さ ≤ g+1 の閉路を持たない。次数 ≤ 2 の頂点を繰り返し消して課金する。残る部分グラフは最小次数 ≥ 3 なので、深さ `j = ⌊g/2⌋` の BFS が `3·2^{j−1} > t` 個の頂点を生み、矛盾する。
- 検算: `3·2^{2u} > t` は常に成り立つ（t < 2×10^5 で総当たり確認済み）。
- **テスト**: 小さなランダム多重グラフで critical 辺を総当たりで数え、`≤ 2t` を確かめる。

### 1.5 Lemma 6.3（一様標本での距離、p.30、l.1439）

- 主張: 残余 U が `h > 32t` 本の辺を持ち、S をその一様な 16t 辺部分集合とする。`d_S(x,y) > g·a_e` となる辺 e の個数の期待値は ≤ h/8（非連結の対を含む）。
- 証明: 後ろ向き解析。U\S から一様に e を選ぶと、S∪{e} の中で各辺は同じ確率で e になる。証人が無いのは e が S∪{e} で critical のとき。期待値は ≤ `(h−16t)·2t/(16t+1) < h/8`（数値で確認済み）。
- **テスト**: 多数の乱数種で、`d_S > g·a_e` の割合の平均が ≤ 1/8 であることを経験的に確かめる。

### 1.6 Sec 6.2 Algorithm 6 `Estimate(S, Q)`（p.31〜33、l.1455〜1508）

**入力** 正の重みの標本グラフ S（辺は O(t) 本）、端点が相異なる要求 h 個。**出力** 上界の表、要求ごとの表の添字または非連結フラグ。

```cpp
T = pow2_ge(4 * t);                         // l.1473
sort S by (w, id);                          // 隣接ランの併合ソート O(t log t)
// 帯（band）: 未割当の最小の重み a が帯を始め、a ≤ w < T·a の重みを含む（T·a は log2 T 回の倍化）
// Kruskal 掃引: 結合のたびに二分の親ノード（重み・帯 id）を作る → 併合森（l.2）
for (q : Q) if (find(x) != find(y)) disc[q] = true;
            else band_of[q] = band(LCA_mergeforest(x, y));     // l.3（Lemma 3.9）
for (a : 要求のある帯の anchor を昇順に) {                        // l.4
  // 商 Q_a（l.1481〜1488）: 重み < a/T² の辺を縮約（判定は T²w < a）。
  //   選ばれた森の辺を、縮約の切り値を下回った時点で挿入する。
  //   小さい側のリストを付け替えるラベル管理。2 本のカーソルで窓 [a/T², T²a] を管理。
  //   残す辺: 窓の中にあり、縮約後の端点が異なるもの。頂点は残す辺に接するものだけ。
  build Q_a; map demand endpoints by component label;            // l.5
  ell = least ℓ with 2^ℓ ≥ t·T²;   // 尺度 Δ_i = 2^i·a, i = 0..ell
  H = pow2_ge(pow(16*t, 5));
  for (i = ell; i >= 0; --i) {                                    // l.6-7
    perm = uniform_permutation(V(Q_a));  j = uniform_int(0, H-1);
    // 半径 R = Δ(1 + j/H)。比較は H·dist ≤ (H+j)·Δ で行う（l.1493）
    best[] = +∞（タイムスタンプで遅延初期化）; label[] = none;
    for (c : perm) radius_limited_dijkstra(c, R):                 // 二分ヒープ
        // 頂点 z を距離 d で確定したとき、d < best[z]（厳密）の場合だけ
        // best[z] = d と更新して辺を走査する。そうでなければその訪問を捨てる。
        // 最初の改善で label[z] = c（恒久）。
  }
  // l.8-9: 各商成分で、粗い尺度から細かい尺度へ分割木を作る。
  //   尺度 Δ の部分 = (親の部分, label) の対。安定計数ソートで群分けする。
  //   新しい部分ごとに大域表へ値 4Δ + a（= a·2^{i+2} + a）を書く。
  //   最も細かい部分の下に、頂点ごとの葉を 1 つずつ付ける。LCA の前処理。
  for (q in band a) idx[q] = table_index(LCA(leaf(x'), leaf(y')));   // l.10
}
return {table, idx, disc};                                         // l.11
```

- **不変条件**: 尺度 Δ の部分に属する頂点は、その尺度で同じ中心を持つ（l.1507）。最上位の尺度 `Δ ≥ tT²a` では、最初の中心が商成分全体を覆う（Lemma 6.7(1)）。
- **計算モデル**: 重みは比較・加算・倍化（T²、H 倍、`(H+j)Δ`）。H と j は整数で、`log2 H = 5·log2(16t)` 程度の多語整数になる（`thresholds.md` §5）。Dijkstra は二分ヒープ（Lemma 3.2、操作ごとに log）。
- 【補完】`ell` の定義「最後の尺度が `≥ tT²a` となる最小の ℓ_a」は、整数で `2^ℓ ≥ t·T²` と同値（a > 0 だから）。

#### Lemma 6.4（商の路の持ち上げ、p.32、l.1509）

- 主張: x, y が連結な相異なる標本頂点で、併合の重みが β、帯の anchor が a のとき、Q_a での像は相異なり、存在し、連結である。商での距離 d について `a ≤ β ≤ d ≤ d_S(x,y) ≤ d + a`。
- 決定的な主張。使う事実は `(t−1)β < T²a`（`T > t−1`）と、持ち上げで足される長さ `t²a/T² ≤ a`（`T ≥ t`）。
- **テスト**: ランダムな S で、すべての連結要求について 4 つの不等式を確かめる。

#### Lemma 6.5（1 つの尺度での分離、p.33、l.1530）

距離 d の 2 点が尺度 Δ で異なる中心を得る確率は `≤ H_t(d/Δ + 1/H)`。ここで `H_t = Σ_{i≤t} 1/i`。証明は FRT と同じ順序付けの議論。

#### Lemma 6.6（1 つの尺度のラベル付けの仕事量、p.33、l.1542）

刈り込み付きの探索は、各頂点の「最初に覆う中心」を返す（帰納法による正しさ、決定的）。期待時間は `O((v+e)·log²(t+2))`。走査の期待回数は 1 頂点あたり ≤ H_t、ヒープ操作ごとに log。半径を固定した条件の下でも成り立つ。

#### Lemma 6.7（標本の推定器、p.33〜34、l.1560）

- 主張: t ≥ 2 個のピボット、O(t) 本の辺。表は `O(t log(t+2))` 項、期待時間は `O(h + t log³(t+2))`。非連結の対を識別する。連結な要求について
  `d_S(x,y) ≤ Z`（**決定的**）、`E[Z | S] ≤ 256u²·d_S(x,y)`、`u = ⌈log2(t+2)⌉`。
- 証明の要点: (1) 部分の中で共通の中心までの距離は < 2Δ なので `d_S ≤ 4Δ + a`（Lemma 6.4 による）。(2) `Z ≤ 5a + 8ΣΔ·I_Δ`、`E[Z|S] ≤ 5a + 8H_t((ℓ_a+1)d + ΣΔ/H)`。`H_t ≤ 2u`、`T < 8t`、`ℓ_a+1 ≤ 7u`（t < 10^5 で数値確認済み）、`ΣΔ < 4tT²a` なので、`H ≥ (16t)^5` から `ΣΔ/H ≤ a ≤ d` が出る。(3) 各辺が入る窓は ≤ 5 個なので、商の大きさの合計は O(t)。
- 【注】`ΣΔ/H ≤ a` に必要なのは `H ≥ 4tT²` だけなので、`(16t)^5` は余裕を持たせた値（Mode B で H を下げてよい根拠。H は時間にしか効かない）。
- **テスト**: (a) Z ≥ d_S を全要求で（決定的なので毎回）。(b) `mean(Z/d_S) ≤ 256u²` を経験的に。(c) disc フラグが S の連結成分と一致すること。(d) 表の項数 ≤ c·t·log t。

### 1.7 Lemma 6.8（ピボット経路証明書、p.34〜35、l.1605）

- 主張: `t = O(1 + N/L_N^64)` の、ループの無い instance で、Alg 5 は全辺に Definition 6.1 の証明書を与える。辞書は `O(t log²(N+2))` 項。P は `log³(t+2)` 程度の 2 の冪。**ほとんど確実に停止**し、期待時間は `O(M + N)`（整列済み辞書を含む）。
- 証明の要点:
  1. 受理された辺について、`a* ≤ a_e` かつ `d_S ≤ Z ≤ Pa*`。S 上の最短路が表す物理 walk をつなげたものが証明になる。終端の辺は自分の重みで証明される。
  2. 1 回の試行で、`d_S ≤ g·a_e` の要求は Markov の不等式と Lemma 6.7 から `Pr[Z > P·a_e | S] ≤ 1/8`（`P ≥ 8·256·g·u²` だから）。不合格の期待数は ≤ h/8 + h/8 = h/4。棄却（不合格 > h/2）の確率は ≤ 1/2。
  3. 1 回の試行のコストは `O(h + t log³ t)`。i 回目の試行に到達する確率は ≤ 2^{1−i}。
  4. 受理された回で残余は半分になる。受理は `O(1 + log t)` 回、終端の辺は ≤ 32t 本。辞書の整列は `O(t log³ t)`。`O(t log⁴ t) = O(N)` は、ピボット数の仮定 `t = O(N/L^64)` を使う。
- **乱択の分類**: Las Vegas。失敗（棄却）すると、同じ残余で新しい乱数を引いて再試行する。再試行の上限は無い（ほとんど確実に停止）。
- **テスト**: 全辺 e について `λ_e ≤ a_e` と `dist_{G_P}(x,y) ≤ P·λ_e`（G_P 上の Dijkstra を参照解にする）。辞書が整列済みで重複が無いこと。試行回数と受理率の統計（≥ 1/2 であること）。乱数種を変えても全部の不変条件が成り立つこと。

## 2. Sec 7 Auxiliary Distances to the Owner Pivots（p.35〜41）

### 2.1 Sec 7.1 辺の分類と補助計量（l.1642〜1660）

- 外側では、Sec 5 の owner 分解を **分離サイズ `b = L_N^64`** で使う。`r_v = b_T(v, p(v))`（木上の路の最大辺）、`R_v = D_T(v, p(v))`（木上の距離）、`h = b + 1`。この節のマクロ規則は、局所版（`w ≤ N³σ`）を置き換える。
- owner をまたぐ各辺 `xy` を射影した長さ `A_e = R_x + w + R_y ≤ (2h+1)w`（Lemma 5.2）を、pivot-routing instance の辺長として Lemma 6.8 に渡す。頂点はピボットで、`t = |A|`。
- 名前 λ_e から `d_e = P·λ_e` を作る（名前ごとに 1 回、log2 P 回の倍化）。
- **分類**: owner をまたぐ辺は `2d_e ≤ w` なら **radial**、そうでなければ **macro**。owner の中の辺は radial で、`d_e = 0`。

#### Lemma 7.1（p.35、l.1653）

切断された corridor 辺はすべて macro。重み w の macro は、`λ/(2h+1) ≤ w < 2Pλ` を満たす名前 λ を持つ。切断辺 f について `d_f ≥ w(f) > 0` となるのは、MST の cut 性による。
**テスト**: 全 macro 辺について 2 つの不等式。corridor 辺が全部 macro であること。

### 2.2 Sec 7.2 owner 座標（l.1662〜1690）

- 全ピボットを 1 点 `a` に同一視する。radial 辺を補助長 `w'_e = w_e + d_e` で残し、owner の MST の spoke も全部残す。これらの spoke が新しいグラフの MST `T'` になる。a での正の長さのループは捨てる。`J_v = d_{w'}(v, a)`。ピボットでは `J = 0`。

#### Lemma 7.2（owner 座標の物理的な意味、p.35、l.1668）

- 主張: `J_v` は、v から自分の owner ピボットへの物理経路の長さの上界。`r_v ≤ J_v ≤ R_v ≤ h·r_v`。radial 辺上で `|J_x − J_y| ≤ w'_e ≤ 3w_e/2`。`T'` は同一視後の MST。
- **テスト**: G' 上の参照 Dijkstra で J を出し、不等式を全頂点・全 radial 辺で確かめる。`T'` が MST であること（Kruskal の重み和と一致するか）。

### 2.3 Sec 7.3 幅クラス・カレンダー・原子（l.1692〜1779）

データ構造と手順（l.1693〜1710）:

```cpp
// r_v, R_v を T' で上から下へ: a の子 v は r=R=w(av)。それ以外は r_v = max(r_u, w), R_v = R_u + w
// 木片 P: T'−a の親子辺 (u,v) のうち、区間 [r/4, 4R] が重なるものを残す
//   重なり ⇔ r_v ≤ 16R_u かつ r_u ≤ 16R_v（×16 は倍化 4 回）
// グラフ片 C: G'−a の補助辺に同じ重なり判定を当て、union-find でまとめる（各 P は 1 つの C に入る）
// P の根: 共通ピボットに最も近い頂点
for (C : graph pieces) {
  origin = min_{v∈C, r_v>0} r_v;
  grid = { origin·2^i : i ≥ −7（以上）, ..., max R + 2 オクターブ };   // l.1697-1698
  // Lemma 7.3: C の重なり辺の全域木を最小半径の頂点から根付ける。
  //   親の格子添字から O(1+log(h+2)) 個の範囲で子の r を二分探索する。
  idx_r[v] = 格子添字 i（grid[i] ≤ r_v < grid[i+1]）;
  q_v = grid[idx_r[v] − 5];                 // 32q ≤ r < 64q
  U_plus[v] = R_v より真に大きい最初の格子値;
}
for (各 (C,q) の組) カレンダー: セル [iq,(i+1)q), i = 0..(最大の U+)/q;   // Lemma 7.4
C の中で、全 q のマーカーを粗い方から細かい方へ 1 本の増加鎖に併合する;
// グラフ片をまたぐ辺 uv（r_v > 16R_u の向き）: マーカー弧 U+_u → 16q_v
// 各鎖の連続マーカー弧 + 上記の弧 → DAG。トポロジカル順に処理する
// 原子: ピボット以外の辺のうち w' < 2·max(q_u,q_v) のものの連結成分 Y（union-find）
//   Y の物理全域木（定義辺）とその重み和 L_Y（≤ 2q|Y|）
// 初期化: 各 v に実行可能な上界 R_v を、さらに s に接する辺からの申し出を置く
```

#### Lemma 7.3（重なる範囲のオクターブ幅、p.36、l.1711）

全グラフ片で、最小の r から最大の R までの 2 進格子点の数は（両端の定数個を含めて）O(N)。各頂点の幅と上側マーカーの添字は `O(1 + log log(b+4))` 時間で求まる。
証明の要点: 木片の根では `R_x ≤ 17r_x/16`。残した辺では `R_v ≤ 17R_u`。グラフの重なりで併合しても、結合辺ごとに定数オクターブしか増えない。

#### Lemma 7.4（幅セルの数え上げ、p.36、l.1736）

各 (C, q) のカレンダーのセルの総数と、マーカーの併合時間は O(N)。重み w の木辺の寄与は `Σ_{q>w/64} w/q = O(1)`。

#### Lemma 7.5（補助幅での原子の大きさ、p.37、l.1751）

原子は 1 つのグラフ片と 1 つの幅に属し、**頂点数は < b**。定義辺は、1 辺あたり < 2q の全域木を与える。理由: 定義辺の端点は r が等しく、T' 上の路はピボットを通らないので、ピボットを除いた 1 つの成分（< b 頂点）に入る。

#### Lemma 7.6（p.37、l.1762）

格子とカレンダーの項数は合計 O(N)。構築は `O(m + N log log(b+4))`。原子は < b 頂点。**マーカー弧はすべて数値時間を増やす**（`U+_u ≤ 2R_u < r_v/8`、`16q_v > r_v/4`）。

**Sec 7.3 のテスト（中間状態）**: 全頂点で `32q_v ≤ r_v < 64q_v`、`R_v < U+_v ≤ 2R_v`。片をまたぐ辺で `r_v > 16R_u`。マーカー DAG が非巡回で、弧がすべて値の増加方向であること。セル総数 / N が有界であること。全原子で `|Y| < b`、q と C が一様、`L_Y ≤ 2q|Y|`、`T'[Y]` が連結であること。

### 2.4 Sec 7.4 局所探索・クリッピング・外からの到着（l.1780〜1963）

**族（family）と起動リスト**（l.1781〜1800）:
- 原子は、代表の (P, q) の族に属する。族の中では、代表を T' の先行順（整数ソート）に並べる。連続する代表の間の隙間 `g(i,j)` は木距離（LCA と根からの距離）で求める。
- 族の地平線 `max_{Y∈族}(R_rep(Y) + L_Y)`。`v ∈ Y` では `R_v ≤ R_rep(Y) + L_Y`。
- 族の (C, q) カレンダーを、セル 0 から「開始 ≤ 地平線」まで、またはカレンダーの終わりまで歩く。各セルの開始マーカーの起動リストに、族のレコードを積む。

**族の中の run 管理**（l.1801〜1815）:
- 登録済み原子の連結リストと、未登録の連続 run。セル `[a0, b0)` で最初に due になった最小値 z を含む原子 i で run を分割する。新しくできた部分 run（高々 2 つ）ごとに、i に隣接する境界原子 j の代表 v の native inward copy に、`u = max{b0, z + L_i + g(i,j)}` を申し出る。`u > R_v` か、保留中のキーを下げないなら捨てる。
- 分割と最小値の取り出し（split–findmin）は全体で `O(m + Nτ(N))`（Lemma 3.11）。

**原子の局所表現**（l.1816〜1833）:
- 各原子 Y は、補助長の誘導グラフ `G'[Y]` 全体を使う（重い弦も含む）。原子の外への出口は、その尾に並べる。
- 外への出口の抑制: 尾 u での発出時刻が `> R_u` なら出さない。頭 v への外部申し出が `> R_v` なら捨てる。グラフ片をまたぐ辺は、範囲が小さい側から大きい側への向きだけを残す。
- 族の登録時刻 z と L_Y から、持続する締め切り `z + L_Y`（両端を含む）が決まる。
- Y は cutoff q の replaceable atom（Definition 5.11）。Lemma 5.13 と 5.14 で、根を 1 つに cap した局所階層を作り、Lemma 4.3 で正規化する。内部の単位は ≤ q。

**活性原子の訪問**（l.1835〜1841）: 単一頂点の根なら、due の最小値を 1 回出し、許された出口を緩和して葉を引退させる。内部の根なら、最初に due になったキー D0 で開き、上限 `c = min(原子の締め切り, D0 + S(root))`（両端を含む）を置く。各セルで、名目上の根スロットのうちセルとの交わりが c 以下の時刻を含むものについて `Scan(root, I, c)` を呼ぶ。クリップされたスロットを再開するときは、最初の生きている子の順位から、登録・申し出・締め切りを保ったまま始める。

#### Algorithm 7 `OwnerDistances(T', G')`（p.39、l.1843〜1867）

```cpp

// l.3  w' < 2max(q_u,q_v) の非根辺の成分 Y。発見木（重み和 L_Y）と代表

// l.6  1 回の辺走査で G'[Y] と原子間の出口を集める。各 G'[Y] に LocalHierarchy（Alg 4）を走らせ、幅で cap する
// l.7  各階層の正規化、子の順序、代表、隙間（Lemma 4.3, 4.5）

for (marker : topo_order(marker_DAG))                 // l.10
```

#### Lemma 7.7（カレンダーで切られたスロット、p.39〜40、l.1871）

- 前提: 種付きの順序付き階層で、根は 1 つ、単位は ≤ q。外部申し出は実行可能で、そのタイムスタンプのセルを訪れる前に届き、現在のセルの左端より下には入らない。最初のセルはすべての有限な初期タイムスタンプ以下で始まる。訪れるセルは、保護されたタイムスタンプ（締め切りと等しいものを含む）をすべて覆う。
- 結論: 保護された接頭辞は、すべて自分のセルで発出される。仕事量は `O(M + Nτ(N) + Q + E + C)`。名目スロットが外部格子の内側の境界をまたぐのは高々 1 回なので、各局所走査は高々 2 回で済む（図 2）。

#### Lemma 7.8（外部申し出の時間順序、p.40〜41、l.1919）

原子をまたぐ申し出 `z + w'` は、許された向きで、`z ≤ R_u` かつ `z + w' ≤ R_v` のときだけ残す。効果のある減少は、行き先セルの開始マーカーより前に届く。tight な原子間の一歩は、向きと端点の判定をすべて通る。証明は場合分け（片をまたぐ場合は `U+_u → 16q_v` の弧、同じ片の場合は `w' ≥ q_u + q_v`）。

#### Lemma 7.9（p.41、l.1944）

名前が与えられていれば、Alg 7 は全 J_v を**決定的に** `O(m + Nτ(N))` 時間で求める。`τ(N) = 1 + log log log(N+16)`。
正しさは、マーカー順の帰納法と Lemma 5.14・7.7・7.8 による。

**Sec 7.4 のテスト**: J が G' 上の参照 Dijkstra と一致すること。到着時刻のログで「行き先セルの開始マーカーより前に届く」を確かめる（Lemma 7.8）。族の地平線 `R_v ≤ R_rep + L_Y`。発出値が下界（真の J）を下回らないこと（Lemma 4.6 の「過小評価なし」）。単一原子・単一族・全頂点が 1 つのセルに入る等の退化入力。

## 3. Sec 8 外側階層と単一始点アルゴリズム（p.41〜47）

### 3.1 Sec 8.1 外側の状態グラフと閾値成分（l.1966〜2001）

```cpp
// Alg 8 l.12: radial 辺 e=xy で w_e > J_x + J_y + d_e なら削除（spoke ＋ 迂回路の方が真に短い）
//   owner の木辺は残る（J_v ≥ r_v ≥ w_e）。残った radial 辺は w_e ≤ 2(J_x + J_y)
// 二殻構成（Sec 5.2）を、座標 J、K = 16 で:
//   near: radial 辺で両端の J が正、比が ≤ K² = 256。near 成分ごとに最小の正の J を底とする 16 進格子
//   native shell i(v): a·16^i ≤ J_v < a·16^{i+1}
//   inward 状態 j は殻 {j, j+1}、outward 状態 j は殻 {j−1, j}。窓の中の near 辺は双方向
//   inward で殻の記録を下げる / outward で上げる → 新しい native copy へ
//   far inward は native inward へ下り、far outward は native outward へ上る

//     → 通常 inward ピボット copy
//   通常 outward ピボット copy → child_out → … → v_out → 通常 native outward(v)（0）
//   macro 弧の尾と頭は通常 copy だけ。特別状態は単一状態ブロック
// ブロック DAG の順に、I0/O0（重みを無視した macro 最小値）、I*/O*（最大辺最小化）を伝播 → θ = max(I*,O*)
// 結合（join）: 補助ピボット頂点、corridor 結合（T_A の辺重み）、局所ブロックの MST 辺、状態 → owner の結合（θ で）
```

#### Lemma 8.1（p.42、l.2002）

- 主張: 残った radial 辺は `w ≤ 2(J_x + J_y)`。大域的に最短な radial run を最小座標で分けると、inward 側と outward 側の振れ幅はそれぞれ高々 16 倍。通常グラフはすべての測地線を実現する。macro 弧を除いた拡張後の商は非巡回。
- 鍵: 両端が ≤ M/16 で頂点 M に達する区間の長さは `≥ (2/3)(M − M/16) = 5M/8`。迂回のコストは `≤ M/8 + L/2 < L`。
- **K = 16 は正しさに必須**（16 未満だと実現の議論が成り立たない）。
- **テスト**: 参照の最短路木の各 radial run について、振れ幅の比 ≤ 16。状態グラフ上の Dijkstra の「copy の最小値」が物理距離と一致すること。macro 無しのブロック商で DFS をして閉路が無いこと。

#### Lemma 8.2（macro へのアクセスのボトルネック、p.43、l.2027）

`B0 = max(I0, O0)`、`θ = max(I*, O*)` は同時に有限で、有限のとき `r ≤ θ` かつ `B0 ≤ θ ≤ 4K²h·B0`（K = 16 なので 1024h）。
**テスト**: 全状態で、総当たりの最大辺最小化経路から出した θ と B0 で不等式を確かめる。

#### Lemma 8.3（p.43〜44、l.2053）

任意の W > 0 で、ブロック MST の辺、θ での状態 → owner の結合、重み ≤ W の corridor 辺が、長さ ≤ W の弧で強連結な状態成分を正確に記述する。厳密不等式版（< W）も成り立つ。
**テスト**: ランダムな W で、Tarjan の SCC（弧 ≤ W）と、結合の union-find 成分を状態に制限したものが一致すること。

### 3.2 Sec 8.2 数値尺度と原子の置換（p.44〜45、l.2076〜2142）

```cpp
// 各 macro の名前を「その名前を持つ macro の最小の物理重み」に置き換える（同じ名前の比は ≤ 2P(2h+1)）
F = pow2_gt(2*P*(2*h+1) * sq(8*K*K*h));      // 整数パラメータで 1 回だけ（l.2080）
// 支え: 有限な結合の名前 a と corridor の重み a ごとに区間 [a, F³a]
// 単一状態ブロック（ピボット・特別状態を含む）は、自分の有限な θ 結合だけを出す。内部併合は無い
for (正で単一でない通常ブロック U、有限な結合あり) {
  z_U = θ を最小化する状態; a_U = その名前;
  aligned = (F²·s_U ≥ a_U);                   // 倍化と比較（median pruning、O(log F) 回の倍化）
  if (aligned) 名前の区間の開始 = min(開始, s_U);

// 区間の端点を整列し、重なりと比 < 2 の隙間を併合 → 併合成分ごとに倍化格子
// aligned:   t_U = s_U を名前の大域格子で切り下げた値
// unaligned: t_U = 別格子（Sec 7.3 の補助格子のポインタを使い、両端を定数オクターブ延長）での切り下げ
//   どちらも s_U/2 < t_U ≤ s_U
// 事象（ブロック MST 辺 ≥ t_U、θ 結合、corridor）を整数の格子クラスへ二分探索（O(log log F) = O(τ(N))）
// クラスごとに同時併合（Lemma 3.6）→ partition hierarchy（Def 5.12）
//   補助ノードを抑制し、各ノードで「高さ未満の弧」をトポロジカルソートする
//   物理的な接続木は Sec 5.4 の子商探索で作る（クラス [a,2a) の接続は Lemma 8.3 の厳密版で < 2a の弧）
// ブロック内で辺 < t_U の成分 = 原子（< b 頂点）→ Lemma 5.15: 各原子に Alg 4 を走らせ、cap して置換
```

#### Lemma 8.4（p.44〜45、l.2105）

`b = L_N^64` で、名前が Lemma 6.8 を満たすとき、意味のある局所事象（ブロック cutoff 以上のブロック MST 重み）と有限な状態 → ピボットの結合は `O(m + Nτ(N))` で分類できる（大域格子を含む）。閾値未満の原子は、ピボットを除いた 1 つの成分に入り、< b 頂点。
証明の要点: (1) unaligned なら窓の中の辺は `≤ 4K²h·s_U < a_U/2`。aligned なら `a_U/F² ≤ s_U ≤ F·a_U`。(2) オクターブ数は `O(k log F)`、`k = O(t log² N)`。(3) `w < t_U` の辺は owner も半径も変えない。

- **テスト**: unaligned ブロックの MST 辺がすべて `< a_U/2`。aligned ブロックの意味のある重みが、支えの区間（＋下側の切り下げ境界）に入ること。`s_U/2 < t_U ≤ s_U`。原子が < b 頂点で、1 つの owner と 1 つの r を持つこと。出来上がった階層が Definition 4.1 を満たすこと（子の間の軽い弧の商が非巡回、接続の長さ ≤ c0·h、c0 ≤ 2）。

### 3.3 Sec 8.3 単一始点アルゴリズムと主定理の証明（p.45〜47）

#### Lemma 8.5（先行木の復元、p.45、l.2145）

ゼロ辺の成分を縮約して得た距離から、元の全距離と最短路木を `O(m + n)` で復元する。tight な弧 `d(u) + w(uv) = d(v) < ∞` を向き付きで辿り、最初に発見した弧で木を作る。出力する距離は、木を下りながら元の辺重みを足して計算し直す。
**テスト**: 木の各辺が tight であること、到達可能な頂点を全部張ること、根から足した和が出力距離と一致すること。ゼロ閉路を含む入力。

**期待計算量 `O(m + n log log log n)` の内訳**（主定理の証明、l.2206〜2216）

| 段 | 根拠 | コスト |

## 5. 曖昧点・注意点

1. 【曖昧】Sec 8.1 は `s_U = min_{v∈U} r_v`（l.1999）としているが、Sec 5.4 の局所版は `s_U` を「窓の最下位殻の下端」（l.1184）としている。外側でも Lemma 8.4(1) は「最小半径の v」を使うので、外側は `min r` と読むのが一貫している。
2. 【曖昧】Sec 7.3 の格子は「原点より少なくとも 7 オクターブ下、最大の R より 2 オクターブ上まで」（l.1698）だが、Lemma 7.3 の証明では「定数オクターブ」とだけ書かれている。q = 格子添字 − 5 なので、下側には少なくとも 5 オクターブ要る。7 をそのまま採用する。
3. 【曖昧】局所の閾値 `N > 2L^4` の「2」の役割は明記されていない。Sec 5.4 の不等式（N ≥ 32、h ≤ N、K < 16h）が実際に必要とするのは `N ≥ 28 ∧ h ≤ N`（⇔ `N > L^4`）で、これより弱い（`thresholds.md` §4）。
4. 【曖昧】Lemma 6.8 の主張は辞書の大きさを `O(t log²(N+2))` としているが、証明では `O(t log²(t+2))` になっている（t ≤ N なので矛盾はしない）。
5. 【曖昧】Alg 6 の「帯ごとの scale の木」を最も粗い尺度から作るとき、最上位の尺度で 1 つの商成分がちょうど 1 部分になることは Lemma 6.7(1) から出るが、本文の手順には明記されていない。【補完】最上位の部分 = 商成分。
6. 【曖昧】Alg 7 l.9「根からの直接の申し出」は、G' で a に接する radial 辺（元はピボットに接する辺）の `w'` を、その相手側の native inward copy に置くことと解釈した（J の始点は (a, 0)、l.1819）。Sec 7.3 末の「源に接する辺の申し出」（l.1710）は、J の文脈では根 a のことと読む。
7. 【注】Lemma 6.7 は `H ≥ (16t)^5` を使うが、証明に必要なのは `H ≥ 4tT²` だけ。
8. 【注】N の最小値 `589^64 + 1` では |A| = 1 になりうる。その場合 NameRoutes は空、全辺が radial、J = ピボットからの全 SSSP になり、外側の機構が丸ごと二度手間になる。外側が意味を持つのは、N/b が十分大きいときだけ。
9. 【注】Alg 8 l.5 の基本ケースは、「走査型」Dijkstra（O(N²)）を指定している。定数サイズのときにしか正当化されない選択なので、Mode A で現実の N を扱うときは、二分ヒープ版（Lemma 3.2 の同じ補題にある）を使うのが妥当。出力は同じ。逸脱として記録すること（`thresholds.md` §7）。

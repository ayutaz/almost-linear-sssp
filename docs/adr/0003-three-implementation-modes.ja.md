# 0003. 論文忠実・論文実験・実用の 3 モードの分離

[English](0003-three-implementation-modes.md) | **日本語** | [简体中文](0003-three-implementation-modes.zh-CN.md)

- 状態: Accepted
- 日付: 2026-11-27

## 背景 (Context)
論文のしきい値(外側は `N > L_N^64`、局所は `N > 2 L_N^4`、`L_N = ceil(log2(N+2))`、Sec 2)のため、`N < 2^64` のどの `N` でも、外側の構成は実行されません。したがって、忠実な実装では、現実的な入力はすべて基底ケースで処理されます。構成そのものを調べることと、実用上の速度を出すことには、定数を変えたり、別のデータ構造を使ったりする必要があります。それを論文のアルゴリズムと取り違えてはなりません。

## 決定 (Decision)
- Mode A、`src/paper/`:論文忠実。しきい値は書かれたとおりで、オーバーフローしない整数演算で比べます。基底ケースに入ったことは `Diagnostics.fallbacks` に記録します。
- Mode B、`src/experimental/paper_experimental/`:論文の構造で、しきい値をパラメータ化します。逸脱はすべて `docs/PAPER_MAPPING.md` に挙げます。正しさを確立できない入力は失敗とします。参照アルゴリズムへの自動的な置き換えを、成功として報告することはありません。
- Mode C、`src/experimental/practical/`:実用上の最適化で、それぞれにラベルを付けます。
- ベースラインは `src/baseline/` に置き、論文に似せて変更することはしません。

## 結果 (Consequences)
- 「論文のアルゴリズム」という主張は、Mode A だけを指します。
- 報告では、常に計測時間の隣にフォールバックの割合を示します。
- モード間のコード共有は、明示的な共有部品を通して行い、コピーして手を加える形にはしません。

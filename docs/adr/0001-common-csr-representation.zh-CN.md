# 0001. 所有算法共用的 CSR 图表示

[English](0001-common-csr-representation.md) | [日本語](0001-common-csr-representation.ja.md) | **简体中文**

- 状态: Accepted
- 日期: 2026-11-27

## 背景 (Context)
基准测试要比较基线算法、论文忠实的算法和实验性变体。如果各自使用自己的图布局,耗时的差异就会把算法本身的效果和内存布局的效果混在一起。论文的输入是带有限非负长度的无向多重图 (Sec 2)。

## 决定 (Decision)
`sssp::CsrGraph<W>` (`include/sssp/graph.hpp`) 是所有算法共用的唯一输入类型。
每条无向边在边列表中存储一次,在 CSR 中存储为两条弧(自环为一条);弧带有原始的边 ID。重边、自环和孤立顶点都保留。权重为 `std::uint64_t`(精确,检查溢出)或 `double` (IEEE-754)。无效输入(越界的端点、负数/NaN/inf 的权重)在构造时拒绝。
需要其他结构的算法,在计时区间内从 CSR 构建它,并报告这部分开销。

## 后果 (Consequences)
- 在相同的内存布局和输入上做公平比较。
- 结果 (`SsspResult`) 可以报告父边 ID,用于树的验证。
- 想使用不同布局的算法,要在自己的计时内承担转换的开销。

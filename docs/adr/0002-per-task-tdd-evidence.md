# 0002. Per-task TDD evidence files
- Status: Accepted
- Date: 2026-11-27

## Context
TDD is mandatory and must be auditable. Several agents work in parallel; a single shared log
file would produce constant edit conflicts.

## Decision
Each task has one JSON file `docs/tdd/tasks/<TASK-ID>.json` (format in `docs/tdd/README.md`)
written only through `scripts/tdd.py` (`start`, `red`, `green`, `refactor`, `done`). A RED
event requires a non-zero exit code for the intended reason; GREEN/REFACTOR require exit 0.
`docs/TDD_LOG.md` is generated (`tdd.py log`), never hand-edited. Hooks in `.claude/hooks/`
refuse edits to `src/`, `include/`, `tools/` without RED evidence when
`.tdd/config.json` sets `enforce=true`.

## Consequences
- Parallel work never conflicts on evidence.
- `tdd.py check` can validate the whole history in CI.
- Evidence is generated by running commands, so it cannot be fabricated by editing text.

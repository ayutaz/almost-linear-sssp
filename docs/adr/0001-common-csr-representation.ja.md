# 0001. すべてのアルゴリズムで共通の CSR グラフ表現

[English](0001-common-csr-representation.md) | **日本語** | [简体中文](0001-common-csr-representation.zh-CN.md)

- 状態: Accepted
- 日付: 2026-11-27

## 背景 (Context)
ベンチマークでは、ベースライン、論文忠実のアルゴリズム、実験的な変種を比べます。それぞれが独自のグラフ配置を使うと、時間の差に、アルゴリズムの効果とメモリ配置の効果が混ざってしまいます。論文の入力は、有限で非負の長さを持つ無向多重グラフです (Sec 2)。

## 決定 (Decision)
`sssp::CsrGraph<W>` (`include/sssp/graph.hpp`) を、すべてのアルゴリズムに共通の入力型とします。
無向辺は 1 本ごとに、辺リストに 1 回、CSR に 2 本の弧(自己ループは 1 本)として格納します。弧は元の辺 ID を持ちます。多重辺、自己ループ、孤立頂点は保持します。重みは `std::uint64_t`(厳密で、オーバーフローを検査する)か `double` (IEEE-754) です。不正な入力(範囲外の端点、負・NaN・inf の重み)は、構築時に拒否します。
別の構造が必要なアルゴリズムは、計測区間の中で CSR からそれを作り、その費用を報告します。

## 結果 (Consequences)
- 同一のメモリ配置と入力で、公平に比較できます。
- 結果 (`SsspResult`) は、木の検証のために、親の辺 ID を報告できます。
- 別の配置を使いたいアルゴリズムは、変換の費用を自分の計測の中で払います。
